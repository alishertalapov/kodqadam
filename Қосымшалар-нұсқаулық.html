КодҚадам қосымшалары: Android, iPhone, Windows, macOS

Алдымен негізгі Нұсқаулық.html бойынша сайтты іске қосыңыз (Firebase + GitHub Pages). Қосымшалар сол сайтты ашады, сондықтан деректер, логиндер мен ЖИ бәрінде ортақ болады.

Қандай қосымша, қалай жасалады

AndroidAPK файлы. GitHub өзі құрастырады.
WindowsSetup.exe орнатқышы. GitHub өзі құрастырады.
macOSDMG файлы (M-чип және Intel). GitHub өзі құрастырады.
iPhone / iPadSafari арқылы «Үй экранына» орнатылады. Файл керек емес.
Сайтты жаңартсаңыз, барлық қосымша жаңа нұсқаны өзі көрсетеді. Қосымшаны қайта құрастыру тек сайт мекенжайы өзгергенде керек.

1Файлдарды GitHub-қа жүктеу

  1. Сайт тұрған репозиторийге (мысалы kodqadam) архивтегі native папкасын түгел жүктеңіз: Add file → Upload files → папканы сүйреп әкеліңіз → Commit changes.
  2. .github папкасы жасырын болғандықтан, сүйрегенде жүктелмеуі мүмкін. Сондықтан оны қолмен жасаңыз:
    • Add file → Create new file.
    • Атау өрісіне дәл осылай жазыңыз: .github/workflows/build-apps.yml
    • Архивтегі .github/workflows/build-apps.yml файлын Блокнотпен ашып, мазмұнын түгел көшіріп қойыңыз → Commit changes.

2Сайттың мекенжайын жазу

GitHub-та native/app-config.json файлын ашып, ✏ (Edit) батырмасын басыңыз. siteUrl мәніне сайтыңыздың мекенжайын жазыңыз:

{
  "siteUrl": "https://asem-teacher.github.io/kodqadam/",
  "appName": "КодҚадам",
  "appId": "kz.kodqadam.app",
  "version": "1.0.0"
}

Commit changes басыңыз. Мекенжай / белгісімен аяқталуы керек.

3Қосымшаларды құрастыру

  1. Репозиторийдің жоғарғы жағындағы Actions қойындысын ашыңыз. «Workflows aren't being run» деген жазу шықса, I understand my workflows, go ahead and enable them басыңыз.
  2. Сол жақтан Қосымшаларды құрастыру таңдаңыз → оң жақтағы Run workflow → жасыл Run workflow.
  3. 10–20 минут күтіңіз. Барлық қадамның жанында жасыл ✓ белгісі шығады.
  4. Репозиторийдің басты бетінде, оң жақта Releases бөлімі пайда болады. Сонда 4 файл тұрады:
    • KodQadam-Android.apk
    • KodQadam-Setup-1.0.0.exe — Windows
    • KodQadam-1.0.0-mac-arm64.dmg — Apple M1/M2/M3/M4
    • KodQadam-1.0.0-mac-x64.dmg — Intel Mac
Releases бетінің сілтемесін (мысалы https://github.com/asem-teacher/kodqadam/releases/latest) оқушыларға жіберіңіз. Олар өз құрылғысына керекті файлды жүктейді.
Қызыл ✗ шықса: сол қадамды басып, қате мәтінін көшіріп, маған жіберіңіз — түзетемін. Ең жиі себебі — 2-қадамда siteUrl өзгертілмеген.

4Орнату: оқушыларға арналған

ҚұрылғыҚалай орнату
AndroidAPK-ні жүктеп, ашыңыз. «Белгісіз көздерден орнатуға рұқсат» сұраса, рұқсат беріңіз → Орнату. Play Protect ескертсе: Бәрібір орнату (Install anyway).
iPhone / iPadSafari-де сайтты ашыңыз → Бөлісу батырмасы (шаршы мен жоғары бағыттауыш) → «На экран „Домой“» (Add to Home Screen) → Қосу. Экранда КодҚадам белгішесі пайда болады, ол қосымша сияқты толық экранда ашылады.
WindowsSetup.exe-ні ашыңыз. «Windows protected your PC» шықса: More info → Run anyway. Орнатқаннан кейін жұмыс үстелінде КодҚадам белгішесі пайда болады.
macOSDMG-ні ашып, KodQadam белгішесін Applications папкасына сүйреңіз. Алғаш ашқанда «Apple тексере алмады» деген хабар шықса: System Settings → Privacy & Security → төменде Open Anyway → құпиясөз.
Компьютерлер мен Android-та сайттан да орнатуға болады: Chrome не Edge-де сайтты ашқанда кіру бетінде «Қосымша ретінде орнату» батырмасы шығады.

Неге ескерту шығады және ол қауіпті ме

Windows, macOS және Android ресми дүкеннен тыс орнатылатын қосымшаларға ескерту көрсетеді. Себебі қосымшаға ақылы әзірлеуші сертификатымен қол қойылмаған. Қосымшаның ішінде тек сіздің сайтыңыз ашылады, ол қауіпсіз.

Ескертусіз, ресми дүкендер арқылы тарату керек болса:

  • Google Play: әзірлеуші аккаунты бір рет шамамен $25 тұрады.
  • Apple App Store: жылына шамамен $99. Apple тек сайтты ашатын қосымшаларды жиі қабылдамайды, сондықтан iPhone үшін «Үй экранына қосу» тәсілі ыңғайлы.
  • Windows / macOS: кодқа қол қою сертификаттары ақылы.

Шектеулер

  • Қосымшалар жұмыс істеуі үшін интернет керек: деректер қоры мен ЖИ онлайн.
  • Android қосымшасында CSV файлын жүктеу жұмыс істемеуі мүмкін. Мұғалімнің есептерін компьютерден жүктеңіз.
  • Android-тың жаңа нұсқасын орнатқанда ескісін өшірудің қажеті жоқ, ол үстінен жаңарады.
