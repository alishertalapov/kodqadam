КодҚадам: Firebase-ке қосу нұсқаулығы

Бұл нұсқаулық сайтты Claude-сыз, өз Firebase жобаңызда іске қосуға арналған. Барлығы тегін (Spark жоспары, банк картасы керек емес). Шамамен 30 минут кетеді. Қадамдарды ретімен орындаңыз.

Архивтегі файлдар

index.htmlСайттың өзі. Өзгертпеңіз. config.jsБаптаулар. Тек осы файлды өзгертесіз (Блокнотпен ашуға болады). firestore.rulesДеректер қорының қорғау ережелері. 4-қадамда Firebase-ке көшіресіз. manifest.json, sw.js, icon-*.pngСайтты қосымша ретінде орнатуға арналған. native, .githubAndroid, Windows, macOS қосымшалары. Олар туралы Қосымшалар-нұсқаулық.html файлында жазылған.

1Firebase жобасын ашу

  1. console.firebase.google.com сайтына Google аккаунтыңызбен кіріңіз.
  2. Create a project (Жоба жасау) батырмасын басыңыз. Атауы: мысалы kodqadam.
  3. Google Analytics сұраса, өшіріп қоюға болады. Create project.

2Логинмен кіруді қосу

  1. Сол жақ мәзір: Build → Authentication → Get started.
  2. Sign-in method қойындысы → Email/Password → бірінші қосқышты Enable етіп → Save.
Оқушылар email енгізбейді: олар aigerim.bekova сияқты логинмен кіреді. Сайт логинді ішкі email-ге өзі айналдырады.

3Веб-қосымшаны тіркеп, config.js-ті толтыру

  1. Жобаның басты бетінде (Project Overview) </> (Web) белгішесін басыңыз.
  2. Атауы: kodqadam. «Firebase Hosting» белгісін қоймаңыз. Register app.
  3. Экранда const firebaseConfig = { ... } деген код шығады. Ішіндегі 6 мәнді config.js файлындағы сәйкес жерлерге көшіріңіз:
firebase: {
  apiKey: "AIzaSy...",
  authDomain: "kodqadam-1234.firebaseapp.com",
  projectId: "kodqadam-1234",
  storageBucket: "kodqadam-1234.firebasestorage.app",
  messagingSenderId: "123456789012",
  appId: "1:123456789012:web:abc123..."
},
Бұл кодты кейін де табуға болады: ⚙ Project settings → General → Your apps. apiKey құпия емес, ол сайтта ашық тұра береді. Деректерді 4-қадамдағы ережелер қорғайды.

4Деректер қорын (Firestore) ашу

  1. Build → Firestore Database → Create database.
  2. Орны (location): Қазақстанға жақын, мысалы eur3 (Europe). Production mode таңдаңыз → Create.
  3. Rules қойындысын ашып, ондағы барлық мәтінді өшіріңіз. firestore.rules файлының мазмұнын түгел көшіріп қойыңыз → Publish.
Ережелерді міндетті түрде қойыңыз. Онсыз мұғалім тіркелмейді, оқушылардың нәтижесі сақталмайды.

5ЖИ-ді (Gemini) қосу

  1. Сол жақ мәзір: AI Services → AI Logic → Get started.
  2. Gemini API провайдерін сұрағанда Gemini Developer API таңдаңыз (тегін нұсқа, карта керек емес).
  3. Шебердің соңына дейін Continue басыңыз. Қосымшаны тіркеуді сұраса, 3-қадамдағы kodqadam қосымшасын таңдаңыз.
ЖИ үшін App Check қорғанысы керек (2026 жылғы 2 қарашадан бастап міндетті). Оны сайт орналасқаннан кейін, 7-қадамда қосамыз, өйткені оған сайттың мекенжайы керек.

6Сайтты интернетке орналастыру (GitHub Pages, тегін)

  1. github.com-та тегін аккаунт ашыңыз (мысалы, пайдаланушы аты asem-teacher).
  2. Жоғарғы оң жақтағы + → New repository. Атауы: kodqadam, Public → Create repository.
  3. uploading an existing file сілтемесін басып, архивтегі файлдарды (index.html, config.js, manifest.json, sw.js, барлық icon-*.png) сүйреп әкеліңіз → Commit changes. Қосымшалар керек болса, native папкасын да жүктеңіз.
  4. Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
  5. 1–2 минуттан кейін сол бетте сайттың мекенжайы шығады: https://asem-teacher.github.io/kodqadam/.
  6. Маңызды: Firebase-ке оралып, Authentication → Settings → Authorized domains → Add domain → asem-teacher.github.io қосыңыз.
config.js-ті кейін өзгертсеңіз, GitHub-та файлды қайта жүктеу жеткілікті (Add file → Upload files).

7App Check (ЖИ үшін қорғаныс)

  1. console.cloud.google.com/security/recaptcha ашыңыз. Жоғарыда Firebase жобаңызды таңдаңыз. API-ді қосуды сұраса — Enable.
  2. Create key: атауы kodqadam, түрі Website / Web. Домендер: asem-teacher.github.io. «Checkbox challenge» белгісін қоймаңыз. Create.
  3. Кілттің ID-ін (ұзын жол, 6L... деп басталады) көшіріп, config.js-тегі recaptchaSiteKey: "" ішіне қойыңыз. Файлды GitHub-қа қайта жүктеңіз.
  4. Firebase console: Security → App Check → Apps → kodqadam веб-қосымшасы → reCAPTCHA Enterprise → кілтті қойыңыз → Save.
  5. App Check → APIs қойындысында Firebase AI Logic үшін Enforce басыңыз (бұрын қосылмаған болса).

8Бірінші іске қосу: мұғалім аккаунты

  1. Сайтты ашыңыз: https://asem-teacher.github.io/kodqadam/.
  2. Кіру бетінде «Алғашқы баптау» блогы шығады → Мұғалім аккаунтын жасау.
  3. Атыңызды, email-іңізді және құпиясөзді (кемінде 8 таңба) жазыңыз. Енді бұл аккаунт — сайттың жалғыз мұғалімі. Кейін кіргенде email мен құпиясөзді жазасыз.
Мұғалім тіркелгеннен кейін «Алғашқы баптау» блогы ешкімге көрінбейді. Басқа ешкім мұғалім бола алмайды.

9Оқушыларды қосу және логин тарату

  1. Мұғалім бөлімі → Оқушылар.
  2. Сыныпты жазыңыз (мысалы 9А), төменгі өріске оқушылардың аты-жөнін әр жолға біреуден қойыңыз (Excel-ден көшіріп қоюға болады) → Аккаунттарды жасау.
  3. Жүйе әр оқушыға логин (aigerim.bekova) мен құпиясөз (topa81) жасайды. Логиндер тізімі (CSV) батырмасымен Excel файлын жүктеп алып, әр оқушыға өз логинін беріңіз.
  4. Оқушы сайтты ашып, логин мен құпиясөзін жазып кіреді. Оның нәтижесі бірден «Сынып» бетінде көрінеді.
Оқушы құпиясөзін ұмытса: «Оқушылар» бетінде Құпиясөздерді көрсету батырмасын басып, қайта айтып беріңіз.

Телефонда қосымша сияқты орнату

  • Android (Chrome): сайтты ашып → ⋮ → Негізгі экранға қосу (Add to Home screen / Install app).
  • iPhone (Safari): сайтты ашып → Бөлісу батырмасы → На экран «Домой».
